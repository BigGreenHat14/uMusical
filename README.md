# uMusical
(pronounced micro-musical) 

#About
uMusical is, **essentially**, a multi-track MIDI player for micro:bits that can coordinate playback with the help of radio, serial and a PC.

(by the way, the hex file is micro:bit micropython with the filesystem, you can simply open it with [the editor](https://python.microbit.org) to view its source)
